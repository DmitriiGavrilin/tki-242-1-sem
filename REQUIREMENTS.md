# Кафедра — вариант 6

Последовательный номер назначен по порядку предметных областей в `Task_2.docx`.

## Модель

- Базовый класс: `DepartmentWorker`.
- Наследники: `Lecturer`, `Engineer`.
- Сервис предметной области: `Department`.

Поля компактной учебной модели трактуются так: `name` — основной объект поиска, `category` — тип/отдел/группа, `owner` — связанное лицо или организация, `tags` — признаки и связи, `price` и `quantity` — стоимость и количество, `day` — условный день отчетного периода, `active` — доступность/текущее состояние.

## Операции из задания

1. `allWorkers` — Выдавать сведения о работниках кафедры.
2. `researchProjects` — Выдавать информацию о НИР.
3. `lecturerForClass` — Находить преподавателя по дисциплине и виду занятий.
4. `classTypesBySubject` — Выдавать виды занятий выбранной дисциплины.
